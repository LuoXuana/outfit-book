# 穿搭本（Outfit Book PWA）

一款专为手机打造的轻量家庭穿搭记录本，支持 **iPhone（iOS Safari）** 与 **华为手机（鸿蒙 / Android 浏览器）** 添加到桌面使用。

## 核心特点

- **三大分类**：女士、女孩、男孩独立分类与计数徽章，支持按季节（春/夏/秋/冬）、收藏与场景标签筛选，支持关键词搜索（标题、单品、备注、标签）。
- **纯本地存储**：文字结构存在手机 `IndexedDB`，拍照或相册选图后自动在本地压缩为标准 **`.jpg`**（长边 1440px + 缩略图），不上传任何服务器。
- **穿搭日历**：按月查看每天穿了哪一套，支持「今天穿这套」一键打卡。
- **通用 `.zip` 备份与换机**：一键导出 `穿搭本备份-YYYYMMDD.zip`（内含 `data.json` + `images/*.jpg`），电脑或手机都能直接解压看图；换新手机后支持合并导入或覆盖恢复。

## 本地预览

需要 Node.js（无需安装任何第三方依赖）：

```bash
node scripts/dev-server.mjs
```

启动后访问 `http://localhost:8080`。如果手机和电脑在同一个 Wi-Fi 下，也可以在手机浏览器访问 `http://你的电脑局域网IP:8080` 测试。

## 免费部署上线（给姐姐长期使用）

要让 iOS Safari 和华为浏览器支持「添加到主屏幕」和离线打开，需要通过 **HTTPS** 网址访问。最简单免费的静态托管方式：

1. **Cloudflare Pages** / **Netlify Drop**：直接把整个 `outfit-book` 文件夹拖进去即可生成免费 HTTPS 网址。
2. **GitHub Pages**：将本目录推送到仓库后开启 GitHub Pages（应用内所有路径均采用相对路径 `./`，兼容子路径部署）。

## 添加到手机桌面

- **iPhone（Safari）**：打开网址 → 点底部「分享」图标 → 选「添加到主屏幕」→ 点「添加」。
- **华为手机（华为浏览器 / Chrome）**：打开网址 → 点右下角或右上角菜单 → 选「添加到桌面」或「安装应用」。

## 运行测试

```bash
node --test tests/core.test.mjs
```
